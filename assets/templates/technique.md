# テンプレート: テクニック系(チュートリアル型)

用途: 無料〜低額。検索流入と「この人は実力がある」の証明。

## 構成の型

1. **リード**: この記事で何ができるようになるか + before/after画像の位置指示
2. **前提**: 対象読者のレベル、必要な道具・ツール
3. **手順**: ステップごとに「何をするか → なぜそうするか → 作例画像の位置指示」
   (ステップは5個以内。多くなるなら記事を分ける)
4. **つまずきポイント**: 自分や周りが実際にハマった箇所 →【体験談ポイント】
5. **練習課題**: 読者が今日試せるミニ課題を1つ
6. **締め**: 関連記事への誘導 + CTA

## この型の注意

- 手順の再現性が命。qa-agent は手順どおりに再現できるかの観点で審査する
- 画像なしで伝わらない箇所は必ず [画像: …] 指示を置く
