# 品質チェックリスト(配点付き・100点満点)

qa-agent はこの配点で採点する。80点以上 かつ 必須項目全クリアで合格。

## 必須項目(1つでも落ちたら不合格)

- [ ] 【体験談: …】プレースホルダがAIの創作で埋められていない
- [ ] 【要確認: …】マークが残っていない
- [ ] 技法・ツール操作の記述に明らかな誤りがない
- [ ] NG表現(style-guide.md)を使っていない
- [ ] 他者の記事・画像の無断流用がない

## 採点項目

### 掴み(25点)
- タイトルが記事内容と一致し、想定読者が自分事と感じる(10)
- リード3行で「誰の・どんな悩みに・何を提供するか」が伝わる(10)
- タイトルに検索されやすい語が入っている(5)

### 構成(25点)
- 見出しだけ読んで話の流れがわかる(10)
- 各節が「結論→理由→具体例」の順になっている(10)
- 記事の長さが内容に対して適切(冗長な節がない)(5)

### 中身(30点)
- 読者が「明日できる具体行動」を最低1つ持ち帰れる(15)
- 抽象論だけの節がない(10)
- persona.md の悩みトップ3のどれかに応えている(5)

### 読みやすさ(20点)
- 文体ガイド準拠(一人称・温度感・段落の長さ)(10)
- 誤字脱字・日本語の不自然さがない(10)

## 有料note の追加必須項目

- [ ] 無料部分だけで1本の記事として価値が成立している
- [ ] 有料部分に手を動かせる要素(演習・チェックリスト・作例解説)がある
- [ ] 想定価格に対して分量と具体性が見合っている(競合ブリーフと比較)
